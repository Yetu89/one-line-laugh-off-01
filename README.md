Entry for the [make.fun](https://make.fun) bounty **One-Line Laugh-Off**
([bounty page](https://make.fun/bounty/u-zkhiel-one-line-laugh-off-714618ae)): one funny
one-line joke, under 200 characters. Free entry.

## The line

> My smartwatch congratulated me on 10,000 steps — it counted the three times I paced while waiting for my microwave.

(115 characters, one line, no trailing newline.)

## How to run

Requires Node 22+ (stdlib only, no dependencies):

```sh
node main.ts
```

This writes the line to `/output/entry.txt`. For local testing, override
the output directory:

```sh
OUTPUT_DIR=/tmp/one-line-laugh-off-out node main.ts
```

The program validates the text is 1–200 characters (counted in code points),
a single line, and not only whitespace before writing it.
